# auto_editor — 영상 1차 자동 편집기

영상을 넣으면 아래 작업을 자동으로 합니다.

1. **컷 편집**: 0.45초보다 긴 무음과 "어", "음" 같은 필러워드를 잘라냅니다. 문장 끝에는 짧은 숨 고르기를 남겨서 말이 부자연스럽게 붙지 않게 합니다.
2. **설명 화면**: Claude가 대본을 읽고 그림이 있으면 이해가 쉬워지는 곳을 고릅니다. 이미지 AI가 그 장면을 '플랫 벡터 + 핸드드로잉 카툰' 스타일로 그립니다. 그림 안에는 글자를 넣지 않고, 필요할 때만 8자 이내 키워드를 얹습니다.
3. **개인정보 가리기**
   - 화면에 보이는 전화번호, 주소, 이메일, 차량번호, 계좌번호 등은 모자이크합니다.
   - 말로 한 개인정보는 '삐' 소리로 가립니다.
   - `--blur-faces` 옵션을 주면 얼굴도 모자이크합니다.

## 처음 한 번 설치

1. **Python 3.10 이상**을 설치합니다. 설치할 때 "Add to PATH"에 체크하세요.
2. **ffmpeg**를 설치합니다. 명령 프롬프트에서 `winget install ffmpeg`를 실행하면 됩니다.
3. 이 폴더에서 명령 프롬프트를 열고 `pip install -r requirements.txt`를 실행합니다.
4. API 키를 등록합니다. 명령 프롬프트에서 실행한 뒤 창을 새로 여세요.

```
setx ANTHROPIC_API_KEY "sk-ant-..."     (대본 분석: 필러 판단, 개인정보, 설명 화면 위치)
setx OPENAI_API_KEY "sk-..."            (그림 생성, 둘 중 하나만 있어도 됨)
setx GEMINI_API_KEY "..."               (그림 생성, 대안)
```

키가 없어도 동작은 합니다. Claude 키가 없으면 규칙 기반으로 컷 편집만 하고, 이미지 키가 없으면 설명 화면을 건너뜁니다.

## 사용법

- **가장 쉬운 방법**: 영상 파일을 `영상편집.bat` 위에 끌어다 놓습니다.
- **자동 처리**: `폴더감시.bat`을 실행해 두고 `업로드` 폴더에 영상을 넣으면 자동으로 편집됩니다.
- **명령어로 실행**:

```
python auto_editor.py 내영상.mp4
python auto_editor.py 내영상.mp4 --blur-faces                  # 얼굴도 모자이크
python auto_editor.py 내영상.mp4 --illustration-mode overlay    # 그림을 오른쪽 위 카드로 표시
python auto_editor.py 내영상.mp4 --max-pause 0.7               # 쉼을 덜 자르기
python auto_editor.py 내영상.mp4 --no-illustrations            # 컷 편집과 모자이크만
```

## 결과물 (`<영상이름>_edited` 폴더)

| 파일 | 내용 |
|---|---|
| `<영상이름>_edited.mp4` | 편집본 |
| `report.md` | 무엇을 지웠고, 어디에 어떤 그림을 넣었고, 무엇을 가렸는지 정리한 보고서 |
| `plan.json` | 편집 계획. 고친 뒤 다시 실행하면 반영됩니다 |
| `illustrations/` | 생성된 그림. 같은 이름으로 바꿔 넣으면 그 그림을 씁니다 |
| `transcript.json` | 음성 인식 결과 |

다시 실행하면 대본, 계획, 그림을 재사용하므로 빠르고 API 비용도 다시 들지 않습니다. 처음부터 새로 계획하려면 `--replan` 옵션을 붙이세요.

## 알아두면 좋은 점

- 처음 실행할 때는 음성 인식 모델(small, 약 500MB)과 OCR 모델을 내려받느라 시간이 걸립니다.
- 말이 없는 장면(풍경이나 행동만 나오는 장면)도 '무음'으로 보고 잘라냅니다. 토크·설명형 영상에 맞춰 만든 프로그램입니다.
- 모자이크는 자동 인식이라 놓칠 수 있습니다. 업로드 전에 `report.md`의 개인정보 항목과 영상을 꼭 한 번 확인하세요.
