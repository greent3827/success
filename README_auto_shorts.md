# auto_shorts — 긴 영상에서 쇼츠 자동 생성

긴 영상을 넣으면 아래 작업을 자동으로 합니다.

1. **핵심 구간 고르기**: Claude가 대본을 읽고 앞뒤 맥락 없이도 이해되고 첫 문장이 훅이 되는 20~58초 구간을 고릅니다. 화면 제목, 업로드 제목, 설명, 해시태그도 함께 만듭니다.
2. **세로 화면 만들기 (1080x1920)**
   - 얼굴이 자주 보이는 영상은 얼굴을 따라가며 세로로 잘라냅니다.
   - 화면 녹화나 PPT 강의는 원본을 가운데에 두고 위아래를 흐린 배경으로 채웁니다.
   - 이미 세로인 영상은 그대로 씁니다.
3. **쇼츠용으로 다듬기**: 구간 안의 0.5초보다 긴 쉼을 자르고, 큰 자막과 상단 제목을 넣고, 음량을 유튜브 기준에 맞춥니다.

## 설치

`auto_editor`를 이미 쓰고 있다면 **추가로 설치할 것은 없습니다.** 같은 폴더에 `auto_shorts.py`와 bat 파일만 넣으면 됩니다.

처음이라면 `README_auto_editor.md`의 설치 순서(Python, ffmpeg, `pip install -r requirements.txt`, `ANTHROPIC_API_KEY` 등록)를 따르세요. 이미지 API 키는 필요 없습니다.

Claude 키가 없어도 동작합니다. 그때는 핵심 단어(방법, 꿀팁, 실수, 돈 등), 말 속도, 목소리 크기, 질문형 시작을 보고 규칙으로 구간을 고릅니다. 다만 제목과 설명은 첫 문장을 그대로 쓰기 때문에 품질이 떨어집니다.

## 사용법

- **가장 쉬운 방법**: 영상 파일을 `쇼츠만들기.bat` 위에 끌어다 놓습니다.
- **자동 처리**: `쇼츠폴더감시.bat`을 실행해 두고 `쇼츠` 폴더에 영상을 넣으면 자동으로 만듭니다.
- **명령어로 실행**:

```
python auto_shorts.py 내영상.mp4
python auto_shorts.py 내영상.mp4 --count 5             # 5개 만들기 (기본 3개)
python auto_shorts.py 내영상.mp4 --layout crop         # 얼굴 따라 자르기로 고정
python auto_shorts.py 내영상.mp4 --layout blur --zoom 1.3   # 흐린 배경, 원본을 조금 크게
python auto_shorts.py 내영상.mp4 --max-len 45          # 45초 이하로
python auto_shorts.py 내영상.mp4 --only 2              # 2번만 다시 렌더링
python auto_shorts.py 내영상.mp4 --no-title --no-captions
```

**추천 순서**: 원본을 `auto_editor`로 먼저 편집한 뒤, 그 결과물(`_edited.mp4`)을 `auto_shorts`에 넣으세요. 필러가 지워지고 개인정보가 가려진 상태에서 쇼츠가 나옵니다.

## 결과물 (`<영상이름>_shorts` 폴더)

| 파일 | 내용 |
|---|---|
| `short_01.mp4` … | 완성된 쇼츠 |
| `shorts_report.md` | 쇼츠마다 업로드 제목, 설명, 해시태그(복사해서 쓰기), 원본 구간, 고른 이유 |
| `shorts_plan.json` | 구간 계획. `start`/`end`(초)나 `title`을 고친 뒤 다시 실행하면 반영됩니다 |
| `transcript.json` | 음성 인식 결과 |

다시 실행하면 대본과 계획을 재사용하므로 API 비용이 다시 들지 않습니다. 구간을 처음부터 다시 고르려면 `--replan`을 붙이세요.

## 알아두면 좋은 점

- 화면 아래쪽에는 쇼츠 화면의 좋아요·설명 버튼이 겹치므로 자막을 조금 위쪽에 둡니다.
- 얼굴 인식 모델은 `auto_editor`와 같은 파일(`face_detection_yunet.onnx`)을 씁니다. 없으면 처음 실행할 때 내려받습니다.
- 업로드 전에 영상을 한 번씩 확인하세요. 특히 규칙 기반으로 골랐을 때는 문장 중간에서 시작하거나 끝나지 않는지 봐 주세요.
