# 영상 자동화 스튜디오 (로컬 웹앱)

`auto_editor.py`(영상 편집)와 `auto_shorts.py`(쇼츠 만들기)를 브라우저에서 버튼으로 쓰는 웹앱입니다. 내 컴퓨터 안에서만 열리고, 추가로 설치할 것은 없습니다.

## 처음 한 번: 설치

`처음설치.bat`을 더블클릭하면 파이썬, ffmpeg, 필요한 패키지를 차례로 설치합니다. 처음에는 10분 정도 걸릴 수 있어요. 끝나면 창을 닫으세요.

## 켜는 법

`웹앱실행.bat`을 더블클릭하면 브라우저에 `http://127.0.0.1:8765`가 열립니다. 검은 창을 닫으면 웹앱도 꺼집니다.

`app.py`, `webapp.html`, `auto_editor.py`, `auto_shorts.py`가 같은 폴더에 있어야 합니다.

## 화면 구성

| 위치 | 할 수 있는 일 |
|---|---|
| 위쪽 | ffmpeg, Claude 키, 그림 키 준비 상태 확인. **API 키 설정** 버튼으로 키 등록 |
| 왼쪽 | 영상 끌어다 놓기(→ `업로드` 폴더에 저장), 영상 목록 |
| 가운데 | 원본 미리보기, **영상 편집** / **쇼츠 만들기** / **편집 후 쇼츠까지** 버튼, 옵션, 결과 영상 재생 |
| 오른쪽 | 작업 대기열, 실시간 진행 기록, 취소 |

## 쇼츠 결과 다루기

- 쇼츠마다 **업로드 제목, 설명, 해시태그 복사** 버튼이 있습니다.
- 화면 제목이나 시작·끝 시간을 고친 뒤 **저장 후 다시 만들기**를 누르면 그 쇼츠만 다시 렌더링합니다.
- 편집본이 있으면 "쇼츠는 편집본으로 만들기"에 체크해 두는 걸 추천합니다.

## 알아두면 좋은 점

- 작업은 한 번에 하나씩 순서대로 실행됩니다. 여러 개를 눌러 두면 대기열에 쌓입니다.
- 필요한 파이썬 패키지가 빠져 있으면 위쪽에 안내가 뜨고 **지금 설치** 버튼으로 설치할 수 있습니다.
- 웹앱에서 등록한 API 키는 OneDrive 밖의 사용자 폴더(`%APPDATA%\VideoAutomationStudio\settings.json`)에 저장됩니다.
- 포트가 이미 쓰이고 있다면 `python app.py --port 9000`으로 실행하세요.
